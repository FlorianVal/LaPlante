<threat_model>
Trust boundaries:
- Browser or LAN client input crosses into the Fastify server at HTTP routes.
- Environment variables cross into runtime config.

STRIDE register:
- spoofing: no accounts/auth in v1 by scope; do not add authentication placeholders that imply coverage.
- tampering: validate route inputs in later API plans before writing to SQLite.
- information_disclosure: bind locally for home use and avoid exposing arbitrary filesystem paths.
- denial_of_service: keep health route cheap and add upload limits only in the future photo phase.

Mitigation plan:
- Default `HOST` to `0.0.0.0` for LAN access but document it as local-network use only.
- Keep the server API JSON-only in Phase 1; no arbitrary file serving.
</threat_model>
