<threat_model>
Trust boundaries:
- Route input will later cross into database writes.
- Local SQLite file lives on disk under `data/`.

STRIDE register:
- tampering: invalid intervals or dates could be persisted without validation.
- information_disclosure: storing absolute local paths in public responses can leak machine details.
- denial_of_service: unbounded writes or accidental occurrence pre-generation can bloat the DB.

Mitigation plan:
- Keep query functions typed and route validation in the API plan.
- Store `photoPath` as nullable relative metadata only; no upload handling in Phase 1.
- Do not add scheduled occurrence rows.
</threat_model>
