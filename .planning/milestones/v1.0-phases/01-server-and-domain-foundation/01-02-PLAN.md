<threat_model>
Trust boundaries:
- API date strings will later cross from client input into these shared functions.

STRIDE register:
- tampering: malformed dates or invalid intervals can corrupt schedule summaries if accepted.
- denial_of_service: very large date windows can generate excessive future dates.

Mitigation plan:
- Export validation helpers or throw clear errors for invalid `YYYY-MM-DD`, invalid windows, and `intervalDays < 1`.
- Keep future-date generation bounded by the provided `from` and `to`; reject reversed windows.
</threat_model>
