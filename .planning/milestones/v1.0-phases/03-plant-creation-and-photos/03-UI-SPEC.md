## Component Inventory

Components to build (new):

### 1. AddPlantModal

**Trigger:** Fixed "+" button (always visible, top-right of timeline viewport) + EmptyState click.

**Layout:**
- Backdrop: semi-transparent black overlay (`rgba(0,0,0,0.4)`) covering the full viewport.
- Card: centered horizontally and vertically, max-width 480px, padding `--space-lg` (24px).
- Card border-radius: `--space-sm` (8px).
- Card background: `--color-bg-primary` (#ffffff).
- Card border: 1px solid `--color-border`.
- Card shadow: `0 8px 32px rgba(0,0,0,0.12)`.

**Form fields (top to bottom):**

1. **Modal header**: Title "Add a plant" at `--font-heading` + close X button (lucide `X` icon, 20px) aligned right.
2. **Name input**: Text input, `--font-body`, border 1px `--color-border`, border-radius `--space-xs`, padding `--space-sm` `--space-md`. Label "Name" above in `--font-label` `--font-weight-semibold`. Required. Error border: 1px solid #ef4444 on validation failure.
3. **Photo upload area**: Rounded dashed-border area (2px dashed `--color-border`). Contains: file preview (when photo selected) or upload prompt with camera icon (lucide `ImagePlus`, 24px) and "Choose a photo" text. Label "Photo" above. Optional. Accepted types: image/jpeg, image/png, image/webp, image/gif.
4. **Recurrence field**: Label "Water every" above. Row of 3 preset buttons ("3 days", "7 days", "14 days") + one custom input. Preset buttons: border 1px `--color-border`, border-radius `--space-xs`, padding `--space-sm` `--space-md`, `--font-body`. Active preset: border 2px `--color-accent`, background `--color-accent-light`. Default active: "7 days". Custom input: number input, `--font-body`, width 80px, same border styling as name input.
5. **Action row**: "Cancel" secondary button (text-only, `--color-text-secondary`) + "Add plant" primary button (filled `--color-accent`, white text, border-radius `--space-xs`, padding `--space-sm` `--space-xl`). Both buttons height: 44px (tablet touch target).

**Interactions:**
- Open: backdrop fades in, card scales from 0.95 to 1.0 over 150ms ease-out.
- Close: click backdrop, click X, click Cancel, press Escape. Card scales down over 100ms.
- Name validation: on blur, if empty show "Plant needs a name" in red below the input.
- Photo preview: after file selection, show the image in the upload area (cover-fit, border-radius `--space-xs`). Show "Change photo" text link below the preview.
- Recurrence selection: tap a preset to select it. Tap custom input to deselect all presets and type a number. Custom input accepts integers 1-90 only.
- Submit: "Add plant" button shows loading state (opacity 0.7, cursor wait) during API call. On success, modal closes and toast appears. On error, error message shown below the action row.
- Keyboard: Enter key submits the form when name field has a value.

### 2. Toast

**Position:** Bottom-center of the viewport, 24px above the bottom edge.
**Layout:** Pill-shaped container, max-width 360px, padding `--space-sm` `--space-md`, border-radius `--space-2xl` (48px, fully rounded).
**Background:** `--color-text-primary` (#18181b).
**Text:** `--color-bg-primary` (#ffffff), `--font-body`.
**Icon:** lucide `Check` (16px), white, to the left of text.
**Animation:** Slide up 16px + fade in over 200ms ease-out. Auto-dismiss after 3 seconds, then slide down + fade out over 200ms.
**Stacking:** Only one toast at a time. New toast replaces existing.

### 3. Add Button ("+" FAB)

**Position:** Fixed, top-right corner of the Timeline viewport. `top: --space-md` (16px), `right: --space-md` (16px). `z-index: 10` (above grid, below modal).
**Size:** 44px x 44px (tablet touch target).
**Background:** `--color-accent` (#22c55e).
**Icon:** lucide `Plus`, 20px, white.
**Border-radius:** 50% (circular).
**Shadow:** `0 2px 8px rgba(34, 197, 94, 0.3)`.
**Hover:** Scale 1.05, shadow `0 4px 12px rgba(34, 197, 94, 0.4)`.
**Active:** Scale 0.95.
**Accessibility:** `aria-label="Add plant"`, `role="button"`.

### 4. EmptyState modification

**Change:** Make the entire EmptyState component clickable. Add a subtle "Add your first plant" action cue below the existing text. On click, opens the AddPlantModal.
**Cursor:** pointer on the container.
**Visual feedback:** Background lightens to `--color-bg-primary` on hover.

### 5. PlantRow modification

**Change:** Replace the `<Flower2>` placeholder icon with the plant photo when `plant.photoPath` is truthy.
**Photo rendering:** `<img>` tag, `src="/photos/{plant.photoPath}"`, `alt={plant.name}`.
**Photo styling:** width and height `--icon-placeholder-size` (32px), border-radius `--space-xs` (4px), `object-fit: cover`.
**Fallback:** When `photoPath` is null, keep existing `<Flower2>` icon behavior.
