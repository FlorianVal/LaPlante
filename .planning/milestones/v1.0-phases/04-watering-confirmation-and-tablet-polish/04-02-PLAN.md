  <action>
1. **index.html** -- Replace the current viewport meta tag:
   ```html
   <meta name="viewport" content="width=device-width, initial-scale=1.0" />
   ```
   With this expanded version per D-08:
   ```html
   <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no" />
   ```
   This disables pinch-to-zoom on iPad/tablet. Both `maximum-scale=1.0` and `user-scalable=no` are needed because some iOS versions require both.

2. **vite.config.ts** -- Add `host: true` to the server config section per D-09. The current config has:
   ```typescript
   server: {
     proxy: { ... }
   }
   ```
   Change to:
   ```typescript
   server: {
     host: true,
     proxy: { ... }
   }
   ```
   This makes Vite listen on `0.0.0.0`, printing the LAN IP on startup so the tablet can connect. The Fastify server already binds `0.0.0.0` by default (confirmed in config.ts), so no server change needed.
  </action>
