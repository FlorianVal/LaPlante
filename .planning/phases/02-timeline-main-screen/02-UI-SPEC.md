# Phase 2 — UI Design Contract

> Visual and interaction contract for the Timeline Main Screen. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (custom React components) |
| Icon library | lucide-react |
| Font | system font stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`) |

**Rationale:** This is a single-purpose tablet kiosk app. The primary UI is a custom timeline grid -- no shadcn component maps to this spatial layout. CSS custom properties for design tokens, CSS Modules for component styles. Zero external UI framework overhead.

---

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, cell border radius |
| sm | 8px | Compact element spacing, cell inner padding |
| md | 16px | Default element spacing, row padding, section gaps |
| lg | 24px | Section padding, header bottom margin |
| xl | 32px | Layout gaps, page edge padding |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: none

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 12px | 400 (regular) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

**Usage in this phase:**
- **Body (16px):** Plant names in row headers, time display on the now marker.
- **Label (12px):** Day-of-month numbers in date header cells, day-of-week abbreviations (Mon, Tue, Wed), overdue since date text.
- **Heading (20px):** "Today" label in the date header, empty state heading.
- **Display (28px):** Current time display at the top of the now marker (e.g., "14:30").

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (white) | Page background, timeline grid background, empty cell background |
| Secondary (30%) | `#f8faf8` (off-white with green tint) | Date header row background, plant row hover state, plant name column background |
| Accent (10%) | `#22c55e` (green-500) | Future watering cells (filled green background) |
| Overdue | `#f59e0b` (amber-500) | Overdue cells (filled amber/yellow background) |
| Destructive | `#ef4444` (red-500) | Not used in this phase -- reserved for Phase 4 if needed |

**Additional semantic colors:**

| Token | Value | Usage |
|-------|-------|-------|
| text-primary | `#18181b` (zinc-900) | Plant names, time display, primary readable text |
| text-secondary | `#71717a` (zinc-500) | Day-of-week labels, secondary metadata |
| border | `#e4e4e7` (zinc-200) | Cell borders, row separators, now marker |
| now-marker | `#3b82f6` (blue-500) | Vertical current-time marker line and time badge |
| cell-future | `#22c55e` (green-500) on `#f0fdf4` (green-50) | Future watering cell: green fill with slightly lighter background |
| cell-overdue | `#f59e0b` (amber-500) on `#fffbeb` (amber-50) | Overdue cell: amber fill with slightly lighter background |
| cell-empty | transparent | Days with no watering scheduled |

Accent reserved for: future watering cells, active/selected states. NOT used for generic interactive elements, links, or buttons in this phase.

**Color contrast note:** All text on colored cell backgrounds must meet WCAG AA contrast ratio (4.5:1 for normal text, 3:1 for large text). The label size (12px) on green-500 and amber-500 backgrounds needs verification during implementation -- prefer using the lighter tint background with a darker icon/fill indicator rather than small text on saturated backgrounds.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Not applicable in this phase (no actions yet -- Phase 4 adds tap-to-confirm) |
| Empty state heading | "No plants yet" |
| Empty state body | "Add your first plant to see the watering timeline." |
| Error state | "Could not load plant data. Check that the server is running and try again." |
| Destructive confirmation | Not applicable in this phase |

**Date header format:**
- Day-of-month number: "1", "2", ..., "31"
- Day-of-week abbreviation: "Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"
- Today marker time: "HH:MM" format (e.g., "14:30")
- Today label: "Today" shown once in the date header row

**Plant row label:**
- Plant name (from `PlantResponse.name`)
- No additional text -- the row is self-explanatory via colored cells

## Timeline Grid Specification

### Layout Structure

```
+----------------------------------------------------------+
| Date Header Row                                          |
| [Mon 1] [Tue 2] [Wed 3] ... [| Today |] ... [Sun 13]   |
+--------+-------------------------------------------------+
| Plant  | Day Cells                                        |
| Name   | [_] [_] [G] ... [|] ... [G] [_]                 |
|--------|-------------------------------------------------|
| Fern   | [_] [_] [G] ... [|] ... [G] [_]                 |
| Cactus | [_] [_] [_] ... [|] ... [G] [_]                 |
| Orchid | [Y] [_] [_] ... [|] ... [G] [_]                 |
+--------+-------------------------------------------------+
```

### Fixed Dimensions

| Element | Value | Notes |
|---------|-------|-------|
| Day cell width | 48px | Stable across all rows; fits day number + cell indicator |
| Day cell height | 48px | Matches width for square cells |
| Plant name column width | 160px | Fixed left column; holds icon + name |
| Row height | 64px | Includes 48px cell + 8px padding top + 8px padding bottom |
| Date header row height | 56px | Day-of-month (16px) + day-of-week (12px) + padding |
| Now marker width | 2px | Thin vertical blue line spanning all rows |
| Cell border radius | 4px | Slightly rounded cells |
| Cell gap | 2px | Horizontal gap between adjacent day cells |

### Grid Behavior

| Property | Value |
|----------|-------|
| Default visible window | 14 days (7 past + 7 future, centered on today) |
| Horizontal scroll | Native CSS `overflow-x: auto` with smooth scrolling |
| Scroll initial position | Centered on today column |
| Vertical scroll | Native CSS `overflow-y: auto` if rows exceed viewport |
| Plant name column | Sticky left (`position: sticky; left: 0`) -- stays visible during horizontal scroll |
| Date header row | Sticky top (`position: sticky; top: 0`) -- stays visible during vertical scroll |
| Layout stability | Cell width and row height are fixed (not content-dependent); no layout shift on data changes |

### Now Marker

| Property | Value |
|----------|-------|
| Position | Aligned to the today column's center |
| Visual | 2px vertical blue line (`#3b82f6`) spanning from date header through all plant rows |
| Time badge | Current time (e.g., "14:30") displayed in a small pill at the top of the marker |
| Time badge style | Blue background (`#3b82f6`), white text, 4px border radius, 12px font size |
| Z-index | Above cells but below any future overlay/modal |

### Cell States

| State | Background | Content | Interaction |
|-------|-----------|---------|-------------|
| Empty | transparent | none | none |
| Future watering | `#22c55e` filled circle (20px diameter, centered in cell) | green dot | none (Phase 4 may add interaction) |
| Overdue | `#f59e0b` filled circle (20px diameter, centered in cell) | amber dot | none (Phase 4 adds tap-to-confirm) |
| Today column | `#f8faf8` background tint on the column | same as other states | none |

### Plant Row

| Element | Style |
|---------|-------|
| Plant icon placeholder | 32px square, rounded, `#e4e4e7` background, lucide `Flower2` icon at 20px |
| Plant name | 16px, weight 400, `#18181b`, single line, truncated with ellipsis if too long |
| Row separator | 1px bottom border, `#e4e4e7` |
| Row hover | `#f8faf8` background on the plant name column only |

### Empty State

Displayed when the API returns zero plants.

| Element | Style |
|---------|-------|
| Icon | lucide `Sprout` at 48px, `#71717a` |
| Heading | "No plants yet" at 20px, weight 600, `#18181b` |
| Body | "Add your first plant to see the watering timeline." at 16px, weight 400, `#71717a` |
| Layout | Centered vertically and horizontally in the viewport |

### Error State

Displayed when the API call fails.

| Element | Style |
|---------|-------|
| Icon | lucide `AlertTriangle` at 48px, `#f59e0b` |
| Heading | "Could not load plants" at 20px, weight 600, `#18181b` |
| Body | "Check that the server is running and try again." at 16px, weight 400, `#71717a` |
| Retry button | "Try again" text button, `#3b82f6`, 16px, triggers data refetch |
| Layout | Centered vertically and horizontally in the viewport |

## Loading States

| State | Visual |
|-------|--------|
| Initial load | Show the grid skeleton: date header row with placeholder cells, 3-5 plant rows with gray pulse animation (`#e4e4e7` animated to `#f4f4f5`) |
| Refresh | No loading indicator -- swap data silently when fetch completes |

---

## Viewport and Responsive

| Property | Value |
|----------|-------|
| Primary target | iPad / tablet landscape (1024x768 minimum) |
| Minimum supported | 768px width |
| Maximum tested | 1366px width |
| Orientation | Landscape preferred; portrait acceptable with horizontal scroll |

The layout is NOT responsive in the traditional sense. The grid has fixed dimensions tuned for tablet. On smaller viewports, horizontal and vertical scroll handle overflow. The plant name column stays sticky.

## CSS Architecture

| Property | Value |
|----------|-------|
| Approach | CSS Modules + CSS custom properties |
| Token file | `apps/web/src/styles/tokens.css` -- defines all colors, spacing, typography as custom properties |
| Component styles | One `.module.css` file per component |
| No utility framework | No Tailwind -- the UI is a focused spatial layout, not a multi-page app with varied components |

## Auto-Refresh (Kiosk Behavior)

| Property | Value |
|----------|-------|
| Polling interval | 60 seconds (silent background refetch) |
| Date recalculation | Re-center the grid on today if the date changes (crossing midnight) |
