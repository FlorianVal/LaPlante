## Component Changes

This phase modifies 4 existing components and adds 1 new API function. No new visual components.

### 1. DayCell modification

**Current state:** Renders a cell with state-based styling. No interaction.

**Changes:**
- Add optional `onClick?: () => void` prop.
- Add `cursor: pointer` and `touch-action: manipulation` CSS when `onClick` is provided (i.e., when state is `overdue`).
- Add transition on `background-color` and dot `background-color`: `transition: background-color 0.25s ease`.
- Add `role="button"` and `aria-label="Water {plantName}"` when clickable (accessible name derived from parent context).
- Add `tabindex={0}` when clickable for keyboard accessibility.
- Add `onKeyDown` handler: Enter and Space trigger `onClick`.
- Add active state: scale 0.92 on press (`transform: scale(0.92)`, `transition: transform 0.1s ease`).

**Tap target dimensions:** 56px wide x 48px tall (rectangular cell). Meets Apple HIG minimum 44px touch target on both axes.

### 2. PlantRow modification

**Current state:** Renders DayCells with computed state. No callbacks.

**Changes:**
- Add optional `onConfirmWatering?: (plantId: string) => void` prop.
- Pass `onClick` to DayCell only when `state === 'overdue'`. The callback calls `onConfirmWatering(plant.id)`.
- Pass plant name to DayCell for accessible label (new optional `plantName?: string` prop on DayCell).

### 3. Timeline modification

**Current state:** Orchestrates PlantRows. No mutation callbacks.

**Changes:**
- Create `handleConfirmWatering(plantId: string)` function:
  1. Call `confirmWatering(plantId)` from `api.ts`.
  2. On success: call `refresh()` from `usePlants` hook. The timeline immediately refetches and re-renders with updated schedule (overdue cell gone, new green cells appear).
  3. On failure: show a toast with "Could not record watering. Please try again."
- Pass `onConfirmWatering={handleConfirmWatering}` to each PlantRow.

### 4. api.ts addition

**New function:** `confirmWatering(plantId: string): Promise<void>`

```
POST /api/plants/:plantId/waterings
Content-Type: application/json
Body: { date: <todayISO> }

Returns: 201 Created on success.
Throws: Error on failure.
```

Source: D-03 confirms this endpoint already exists on the server. The client function wraps it.

### 5. tokens.css modification

**Changes:**
- Replace `--cell-size: 48px` with `--cell-width: 56px` and `--cell-height: 48px`.
- Update DayCell.module.css to use `width: var(--cell-width)` and `height: var(--cell-height)`.

### 6. index.html modification

**Changes:**
- Update viewport meta tag: add `user-scalable=no, maximum-scale=1` to disable pinch-to-zoom on tablet.

Source: D-08.

### 7. Server host configuration

**Changes:**
- Change server listen host from `localhost` to `0.0.0.0` so the tablet can access via LAN IP.

Source: D-09.
