<threat_model>
Trust boundaries:
- LAN/browser clients submit JSON bodies and query strings to plant routes.
- Route handlers write validated inputs into SQLite.

STRIDE register:
- tampering: invalid `intervalDays`, malformed dates, or unknown plant IDs can corrupt behavior if accepted.
- repudiation: watering confirmations need stored event rows with `createdAt` to preserve action history.
- information_disclosure: errors should not expose local SQLite paths or stack traces.
- denial_of_service: very large date windows can produce excessive future date arrays.

Mitigation plan:
- Validate bodies and query strings with explicit zod schemas or Fastify schemas.
- Return 400 for invalid date windows and 404 for missing plants.
- Cap accepted schedule windows to a reasonable v1 maximum such as 370 days and return 400 with `"Date window cannot exceed 370 days"`.
</threat_model>
